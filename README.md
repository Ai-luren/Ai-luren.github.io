## 观看体验 / Viewing Experience

- **作品优先**：8 部首页精选 + 15 部完整作品，封面常驻播放入口，点击后在站内查看原比例视频。
- **连续浏览**：桌面与手机共用影院导航，支持作品上一部 / 下一部；切换中英文不重置正在播放的作品。
- **轻量进入**：封面与播放器海报提前解码，详情、荣誉、自媒体账号资料采用统一玻璃弹层；作品库分类切换减少布局跳动。
- **明确返回**：全部作品页始终有固定的「首页 / Home」入口，回到首页首屏；中央「精选作品 / Featured」是独立的作品区导航。
- **按需加载**：只在主动点击播放后请求作品视频；进入精选区域后才低优先级准备作品库页面资源，避免与首屏背景争抢带宽。

## 网站实现 / Behind the Portfolio

<sub>Vite · React · GSAP / ScrollTrigger · OGL / WebGL · ImageKit CDN</sub>

- **影像驱动首页**：首屏和章节背景配合滚动叙事，使用静态首帧与原生媒体兜底。
- **统一交互**：精选作品、获奖图片和自媒体资料采用共享导航及玻璃弹窗；语言切换使用轻量弹性动效。
- **双语与响应式**：简体中文 / English；桌面网格、手机分页，支持键盘焦点、触屏导航和减少动态效果设置。
- **静态资源优化**：作品封面及详情海报解码后展示；跨页面预取 HTML / JS / CSS，不预加载作品视频。
- **按需播放与安全测试**：仅用户主动播放时请求 ImageKit；自动化测试拦截真实 CDN 视频流量。

### 本地运行

需要 Node.js `^20.19.0` 或 `>=22.12.0`。

```bash
npm ci
npm run dev
```

首页：`http://127.0.0.1:5174/`　·　全部作品：`http://127.0.0.1:5174/works.html`

> **重要：** 15 部本地视频原片存放在 Git 忽略的 `assets/videos/works/`，**不会随仓库克隆提供**。本地开发不会自动转而请求 ImageKit；正式网站才使用 ImageKit 视频地址。不要用 `file://` 直接打开 HTML。
