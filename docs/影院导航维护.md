# 影院导航维护

影院仍使用原生 `dialog.showModal()`，顶部导航位于模态 top layer 内，底层页面保持原生 inert。底层首页导航仅在影院期间隐藏，保留测量能力，关闭后恢复。

## 入口与顺序

- `App.jsx` 传入 `FEATURED_PROJECTS` 与选择回调，按真实精选顺序播放。
- `WorksLibrary.jsx` 传入当前 `visible` 筛选结果，换片不改变分类或 URL。
- `CinemaPlayer` 的外层 key 只区分打开 / 关闭，不再随作品 ID 变化。
- 只有 video 和播放器封面按作品 ID 重建；语言切换复用现有 `toggleLang`，不重建视频或重置进度。
- 首尾不循环，禁用相应按钮。换片立即暂停旧视频，准备新封面后释放旧资源，新片暂停在 00:00。

## 顶部导航与布局

四个场景共用 `src/styles/navigation.css` 的几何规则：桌面最大 980px、顶部 14px、高度 58px；手机左右边距 12px、高度 56px。顶部同时兼容 safe-area。首页保留静态 header 与原有菜单事件；作品库、影院、获奖查看器共用 `CinemaNavigation.jsx`。不再运行时测量 / 复制首页样式。

四个场景的左侧品牌统一显示圆形头像和品牌名。品牌名的双语真值是 `src/i18n/dictionary.js` 的 `brand.name`：首页静态 HTML 通过 `data-i18n` 更新，React 导航读取相同字典键。`navigation.css` 必须允许品牌链接内容溢出头像圆形点击框，否则首页早期 `.brand { overflow: hidden }` 会把文字裁掉；头像本身继续使用圆形裁切。维护导航时不要为首页另建组件或重复硬编码英文品牌名。

普通页面显示 Logo / 品牌、语言、菜单；弹窗显示同位置的 Logo / 品牌、语言、关闭。首页桌面也使用原有章节菜单。作品库菜单使用原生 dialog，章节链接由 `src/navigation/links.js` 管理，返回精选放在作品页内容区。影院期间隐藏首页 header、卸载作品库导航；获奖查看器期间隐藏并 inert 底层页面。获奖查看器的模糊放在固定伪元素背景层，避免带滤镜的滚动祖先让顶部导航随图片滚走。`scrollbar-gutter: stable` 保留滚动条空间，避免滚动锁定造成胶囊横移。

影院继续使用原生 dialog。获奖图片查看器保留图片、缩放及圆形箭头，仅加共享导航、背景隔离、焦点循环与关闭恢复。首尾和循环规则按两个查看器原有业务逻辑各自保留。

视频继续保持真实比例、圆角和手动播放。高度预算统一扣除顶部导航与间距、标题 / 奖项的实测高度、整条作品操作区及底部 safe-area；通过有界测量兼顾窄屏标题换行。普通手机与桌面优先完整显示整组内容，真正较矮的视口保持可读媒体尺寸并使用单一弹窗滚动。

桌面仅在视频两侧各有至少 80px 余量时，将同一对 48px 箭头放在视频两侧；否则放在信息区下方。手机始终采用“上一部圆形按钮 / 序号 / 下一部圆形按钮”，下一行显示次级作品库 CTA。没有重复箭头，不覆盖原生控制条。

获奖查看器读取 `naturalWidth / naturalHeight`，不再给 Lightbox 图片统一写入 HTML 高度，也不继承作品列表 3:4 规则。图像、说明和切换按钮共同计入视口预算。桌面箭头距图像 20px；手机箭头位于说明下方。原图完整展示、无裁切 / 去黑边，图片本身复用内容圆角 Token（桌面 18px、手机 16px），不额外绘制黑色画框或第二层描边。内嵌的主办方 Logo、编号、邮件说明及截图边缘保持原样。

导航材质复用现有 panel Token，模态遮罩复用 modal Token；降低透明度和缺少滤镜时保留不透明降级。没有新增全屏模糊层、滑动换片手势或播放器依赖。

## 返回与历史

- 首页的全部作品入口与影院入口共用 `src/navigation/links.js` 的相对链接，兼容子路径部署。
- 作品库中的“返回作品列表”只关闭弹窗，保留筛选、URL 与打开前的页面滚动位置。
- 关闭暂停并释放视频，焦点回到最初点击的作品卡片。
- 不创建额外历史记录。浏览器触发原有 `popstate` 时关闭影院，保留浏览器已有的页面 / 锚点返回行为。
- 离开页面与切入后台均暂停声音。
