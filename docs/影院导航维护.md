# 影院导航维护

影院仍使用原生 `dialog.showModal()`，顶部导航位于模态 top layer 内，底层页面保持原生 inert。底层首页导航仅在影院期间隐藏，保留测量能力，关闭后恢复。

## 入口与顺序

- `App.jsx` 传入 `FEATURED_PROJECTS` 与选择回调，按 `src/data/projects.js` 中 `FEATURED_PROJECT_IDS` 真实精选顺序播放（`01, 02, 06, 03, 04, 07, 08, 05`），**不使用全部作品库前八项的原始顺序**；手机的 4+4 分页和播放器切换必须一致。
- `WorksLibrary.jsx` 传入当前 `visible` 筛选结果，换片不改变分类或 URL。
- `CinemaPlayer` 的外层 key 只区分打开 / 关闭，不再随作品 ID 变化。
- 只有 video 和播放器封面按作品 ID 重建；语言切换复用现有 `toggleLang`，不重建视频或重置进度。
- 首尾不循环，禁用相应按钮。换片立即暂停旧视频，准备新封面后释放旧资源，新片暂停在 00:00。

## 顶部导航与布局

首页、作品库与站内各类详情共用 `src/styles/navigation.css` 的几何规则：桌面最大 980px、顶部 14px、高度 58px；手机左右边距 12px、高度 56px。顶部同时兼容 safe-area。首页保留静态 header 与原有菜单事件；作品库、影院、获奖查看器、账号资料与 AI 实验室详情共用 `CinemaNavigation.jsx`。不再运行时测量 / 复制首页样式。

首页及三类详情查看器的左侧品牌显示圆形头像和品牌名；普通全部作品页例外，使用 A+ 圆形箭头 +「首页 / Home」，整组链接到 ./index.html 首屏，且桌面手机一致。品牌名的双语真值是 `src/i18n/dictionary.js` 的 `brand.name`：首页静态 HTML 通过 `data-i18n` 更新，React 导航读取相同字典键。`navigation.css` 必须允许品牌链接内容溢出头像圆形点击框，否则首页早期 `.brand { overflow: hidden }` 会把文字裁掉；头像本身继续使用圆形裁切。维护导航时不要为首页另建组件或重复硬编码英文品牌名。

首页普通页面显示 Logo / 品牌、语言、菜单；作品库普通页面显示 A+ 首页返回、语言、手机菜单（桌面中部四项导航）；弹窗仍显示 Logo / 品牌、语言、关闭。首页桌面展示四项一级导航；手机菜单沿用共享展开/关闭交互。作品库菜单使用原生 dialog，章节链接由 `src/navigation/links.js` 管理；作品库标题上方不再放单独的「返回精选作品」链接；顶部固定 A+ 返回统一回首页 Hero，桌面中央「精选作品 / Featured」和手机菜单里的该项仍可进入 #projects。影院期间隐藏首页 header、卸载作品库导航；获奖查看器期间隐藏并 inert 底层页面。获奖查看器的模糊放在固定伪元素背景层，避免带滤镜的滚动祖先让顶部导航随图片滚走。`scrollbar-gutter: stable` 保留滚动条空间，避免滚动锁定造成胶囊横移。

影院继续使用原生 dialog。获奖图片查看器保留图片、缩放及圆形箭头，仅加共享导航、背景隔离、焦点循环与关闭恢复。首尾和循环规则按两个查看器原有业务逻辑各自保留。

精选与作品库卡片为 3:4 封面，详情海报可能是独立 16:9 素材：悬停、触碰或聚焦卡片时预热详情海报；点击后海报解码成功才显示弹窗，失败退回当前卡片封面；不得提前请求 ImageKit 视频。视频继续保持真实比例、圆角和手动播放。高度预算统一扣除顶部导航与间距、标题 / 奖项的实测高度、整条作品操作区及底部 safe-area；通过有界测量兼顾窄屏标题换行。普通手机与桌面优先完整显示整组内容，真正较矮的视口保持可读媒体尺寸并使用单一弹窗滚动。

桌面仅在视频两侧各有至少 80px 余量时，将同一对 48px 箭头放在视频两侧；否则放在信息区下方。手机始终采用“上一部圆形按钮 / 序号 / 下一部圆形按钮”，下一行显示次级作品库 CTA。没有重复箭头，不覆盖原生控制条。

获奖查看器读取 `naturalWidth / naturalHeight`，不再给 Lightbox 图片统一写入 HTML 高度，也不继承作品列表 3:4 规则。图像、说明和切换按钮共同计入视口预算。桌面箭头距图像 20px；手机箭头位于说明下方。原图完整展示、无裁切 / 去黑边，图片本身复用内容圆角 Token（桌面 18px、手机 16px），不额外绘制黑色画框或第二层描边。内嵌的主办方 Logo、编号、邮件说明及截图边缘保持原样。

导航材质复用现有 panel Token，模态遮罩复用 modal Token；降低透明度和缺少滤镜时保留不透明降级。没有新增全屏模糊层、滑动换片手势或播放器依赖。

AI 实验室的 `ExperimentFlip` 为一屏式轻量项目详情（桌面左右布局、手机上下布局），保留共用影院导航和方向键分页；GitHub 仅作为次级源代码外链。四个平台账号资料支持原账号内左右循环而不重建导航；手机/粗指针访问 GitHub 等站外地址时弹出独立 `ExternalLinkSheet`，Escape 只关闭最上层确认面板。详见 [AI 实验室与外链维护](./AI实验室与外链维护.md)。

## 返回与历史

- 首页的全部作品入口与影院入口共用 `src/navigation/links.js` 的相对链接，兼容子路径部署。
- 详情底部统一显示无箭头的「查看全部作品 / View all work」次级玻璃胶囊：hover/focus 仅轻微提亮边框和表面，不位移。从作品库打开时按钮只关闭弹窗、恢复筛选/URL/滚动位置；从首页精选打开时链接进入 `works.html`。顶部 × 始终只关闭弹窗并返回原触发位置，不新增导航按钮。首页精选区同名 CTA 为无箭头、无项目数的纯文字站内入口，悬停只渐显细线/提亮文字，不出现位移。
- 关闭暂停并释放视频，焦点回到最初点击的作品卡片。
- 不创建额外历史记录。浏览器触发原有 `popstate` 时关闭影院，保留浏览器已有的页面 / 锚点返回行为。
- 离开页面与切入后台均暂停声音。

```bash
node scripts/check-project-library.mjs
npm run build
npm run check:i18n

```

播放器打开和换片时不设置视频 `src`；相关回归脚本应验证 `paused`、`currentTime=0`、`readyState=0`，不能等待 `loadedmetadata`。只有按下播放按钮后才等待视频元数据或首帧。

导航专项验证 360、375、393、430、1280、1440、1920px：导航坐标、同一个 video 上的语言切换、精选与筛选序列、首尾禁用、原生焦点隔离、ESC、返回、历史以及短视口内部滚动。真实 3:4 影片素材尚缺，不标为已验证。
