# 设计系统统一说明

统一采用现有 `card-surfaces.css` 材质规范与 `apple-system.css` 的文字、色彩和动效规范。以下是组件的语义分工，不要求每个场景使用相同背景或相同圆角。

| 语义 | Token | 当前规则 |
| --- | --- | --- |
| 首页底层 | `--apple-bg` | 保持原有黑色及影像背景 |
| 独立内容页 | `--portfolio-page-surface` | 中性 `#0b0c0f`；作品库 `--library-bg` 仅为本地别名，保留同色首屏兜底 |
| 全屏模态材质 | `--portfolio-modal-surface` / `--portfolio-modal-blur` | 菜单与影院共用 90% 深灰、28px 模糊；影院只在 `::backdrop` 处理一层 |
| 不透明降级 | `--portfolio-modal-solid` | `#0c0c0d`；降低透明度或两种模糊属性均不支持时生效 |
| 玻璃面板 | `--portfolio-panel-surface` / `--portfolio-panel-border` / `--portfolio-panel-blur` | 沿用现值；card 别名继续兼容首页 |
| 图标控件默认 | `--portfolio-icon-surface` / `--portfolio-icon-border` | 沿用已展开菜单按钮的中性材质：白色 10% 表面、34% 描边 |
| 图标控件反馈 | `--portfolio-icon-hover-surface` / `--portfolio-icon-active-surface` | 同一中性表面的 14% / 18%，不改变控件尺寸 |
| 主次文字 | `--apple-text` / `--apple-secondary` / `--body-text` | 标题、辅助文字、需要更高对比的播放器信息各用其现有语义 |
| 面板 / 内容 / 小块 | `--portfolio-panel-radius` / `--portfolio-content-radius` / `--portfolio-tile-radius` | 24 / 18 / 12px；原作品封面不变，视频手机端沿用 16px 限制 |
| 胶囊 / 圆形按钮 | `--portfolio-control-radius` / `--portfolio-icon-radius` | 999px / 50%，不统一尺寸 |
| 控件动效 | `--apple-duration-control` / `--apple-ease` | 180ms 与现有系统缓动；减少动画时取消过渡，不等同禁用模糊 |
| 键盘焦点 | `--apple-blue` | 2px 实线、4px 偏移；关闭和播放控件保持一致 |

## 生效顺序

首页仍是静态 HTML 与 React Portal 的混合结构。组件 CSS 之后加载 `card-surfaces.css`，再加载 `apple-system.css`。

首页历史样式里存在多个 `!important`。不全站清理这些规则；`apple-system.css` 的末尾仅对**已展开菜单的 `.nav-toggle`、影院关闭与播放按钮**建立最终材质规则。真正可见的菜单关闭按钮是 `.nav-toggle` 变形后的图标，隐藏的 `.mobile-nav-close` 不作为视觉参照。

媒体上的播放按钮通过同一控件契约引用现有 panel 表面，保证明亮画面上的图标对比度；菜单关闭和影院关闭保持相同 Token。

这组共享规则不设置尺寸或定位，不影响关闭逻辑、菜单图标变形或视频比例计算。播放器 CSS 保留布局与裁切，材质状态集中由共享规则管理。

降级分支保持限定在导航抽屉和影院 `::backdrop`，不修改全局透明度变量。降级菜单背景不做整层淡入淡出，内容动效和关闭时序保留。
