# 本地作品工作台使用指南

> 工作台：<http://127.0.0.1:5190/>（仅本机）。修改不会自动上传 ImageKit、提交 Git、合并分支或部署 Netlify。

## 入口与布局

运行 `npm run covers` 启动工作台。作品库默认显示 **8 部首页精选**；其他作品通过「商业广告、创意短片、海外产品广告、视觉实验」四个分类查看。右上角「＋ 新增作品」随时可用；搜索覆盖全部作品（`/` 或 `⌘K` 定位搜索框，`Esc` 清空），切换分类自动退出搜索。搜索不允许拖拽，以免误排序。

点击作品封面进入编辑。**桌面全屏双栏**：左侧是本地 MP4 播放器、进度条和选帧区；右侧为 **「作品管理／封面与海报」两个 Tab**。「作品管理」集中版本切换、拖拽排序、重命名、共享作品名称、ImageKit、精选和安全归档；「封面与海报」负责选帧及历史，减少重复切换。顶部「上一部／下一部」默认按**全部作品的正式排序**连续切换（也支持 `Option + ←/→`），即使从首页精选、商业广告或搜索结果进入，也允许跨分类；切到其他分类时，底层作品库会跟随切换，关闭详情就能看到当前作品；首尾循环切换：最后一部的下一部回到第一部，第一部的上一部回到最后一部。切换后视频保持暂停，默认显示当前排序的第一个可用版本；未保存草稿先提醒。右上「关闭」和 `Esc` 可退出。

**仅支持桌面端（Mac）**：请用电脑浏览器打开，窗口宽度至少 921px。工作台不再维护手机布局和触屏长按拖拽；窄屏只显示电脑端提示。**公开作品集网站**继续支持手机浏览。

## 常用操作

| 任务 | 最短路径 |
| --- | --- |
| 切换上一部／下一部 | 编辑页顶部箭头，或不在输入框时按 `Option + ←/→`；不受当前筛选 Tab 限制，按全部作品的顺序连续浏览，允许跨分类并循环切换 |
| 播放与快进 | 左侧点击视频画面或「▶」播放/暂停；拖动视频下方的进度条即可定位 |
| 视频选帧 | 右侧切换「封面与海报」，再点「更换封面／更换海报」→ 拖动视频时间轴定位 → 上一帧／下一帧或方向键逐帧微调 → 一个保存按钮完成取帧与替换 |
| 真正的最后一帧 | 点「尾帧」提取真实视频末帧；「首帧」可回到开头，不把音频容器的尾部误认为最后一幅画面 |
| 精确逐帧 | 同排只保留「首帧／上一帧／下一帧／尾帧」四个等高按钮。按住 ← / → 可以连续移动；选帧时上方播放器直接显示毫秒，不再出现秒数输入框或 FPS 数值。 |
| 3:4 作品封面 | 默认**完整保留原始画面**，必要时加模糊背景填充；没有「裁切／不裁切」双模式 |
| 原比例播放器海报 | 在右侧「视频版本」选择 A/B/C，再切换到「封面与海报」更换当前版本的原比例海报。它保留 9:16、16:9、21:9 等实际画幅；不同版本各自独立 |
| 旧封面历史和恢复 | 在「作品封面」或「播放器海报」下方点「历史」→ 左右对比当前图与旧图 → 选择日期 →「恢复这张封面／海报」；恢复前会再次备份当前图片 |
| 导入封面图片 | 选帧区直接上传 JPG、PNG 或 WebP；替换原比例海报时图片比例必须匹配当前视频 |
| 整部作品名称（中英文） | A/B/C 所有视频版本共用一组标题，网站卡片只显示这组名称。作品库单击标题原位编辑，`Enter` 保存、`Esc` 取消，失焦不静默重命名；详情右侧也可修改。英文标题改变会同步本地 MP4、封面、海报及路径映射，**不会修改 ImageKit 地址** |
| 新增视频版本 | 右侧「添加视频版本」→ 选择 MP4 → 左侧预览 →「保存为版本 C」（字母随版本数递增）。**中英文名称默认自动生成，无需填写**；只有需要自定义名称才展开「自定义版本名称」。新版本有独立 MP4 和播放器海报，不覆盖旧版本，也不上传 ImageKit |
| 修改单个版本名称 | 右侧「视频版本」→ 点击版本标签旁铅笔或「重命名当前版本」→ 修改中英文标签 → 保存；`Esc` 取消。**只改该版本，不改整部作品标题，不需要双击** |
| 调整视频版本播放顺序 | 右侧「视频版本」按住任一版本标签拖到目标位置，松手**自动保存**；也可聚焦标签按 `Shift + ←/→`。第一个标签是网站播放器首次打开的默认视频，例如可将「精密入席」放到首位。排序不改主版本身份、不移动 MP4/海报、不交换 ImageKit 链接；上线需重新发布网站 |
| ImageKit 地址 | 「作品管理」→「发布与预览」右侧提供「打开 ImageKit ↗」媒体库快捷入口；单击地址编辑。可粘贴 `https://ik.imagekit.io/Ailuren/videos/FormFunk-E.mp4`（或带 `tr:orig-true` 的链接），输入框自动显示 `FormFunk-E`；保存生成 `https://ik.imagekit.io/Ailuren/tr:orig-true/videos/FormFunk-E.mp4`。也能只输入文件名或带 `.mp4` 文件名。其他账户、非 MP4 地址会被拒绝；只保存本地，不自动上传 |
| 首页精选 | 作品库卡片点击星标，选择要被替换的精选作品；首页固定 8 部 |
| 排序 | 直接按住封面拖动；桌面鼠标拖动封面并松开即可自动保存，短时间内可撤销 |
| 新增作品 | 作品库「＋ 新增作品」→ 拖入或选择 MP4（默认素材目录收在可选折叠区）→ 选画面 → 校验双封面 → 填写共享作品标题及分类 → 本地保存 |
| 归档整部作品 | 右侧「作品管理」底部「归档整部作品」→ 输入「归档」确认；只从作品库及待发布页面隐藏，不删除文件。**精选作品必须先替换出精选** |
| 归档单个版本 | 「作品管理」中选中任何一个视频版本（包括原始 `main`）→「归档当前视频」。至少保留一个有效版本；原文件和 ImageKit 链接不删除，可在回收站恢复 |
| 恢复归档 | 作品库右上角「回收站」→ 找到作品或版本 →「恢复」，自动返回对应作品。没有永久删除入口 |

## 回收站与安全边界

- **不提供永久删除。** 回收站只在 `src/data/archive-state.json` 标记整部作品或单个扩展版本为已归档；`auto-projects.json`、旧作品数据、MP4、封面、历史版本和 ImageKit 文件均不物理删除，恢复后显示原记录。所有操作通过本机授权 API 执行，产生 `.cover-studio/project-revisions/archive-*.json` 日志。
- 已归档的作品或扩展视频版本从本地列表及网页**下次部署版本**中隐藏；已上线的 Netlify 网站不会自动更新，已知 ImageKit 直链也不会因归档失效。回收站是整理与误删保护，不是保密或撤回公开传播的手段。
- 首页精选固定八部作品：归档精选作品前，先替换精选位置，避免首页作品数量不足。只要有其他可用版本，原始 `main` 也可单独归档；作品的最后一个版本不能单独归档，需要整理时使用「归档整部作品」。
- 归档不释放磁盘空间，且原项目的视频版本记录仍然存在。不要把 `.cover-studio/` 或 `src/data/archive-state.json` 当作普通缓存清理。隔离验收命令：`npm run check:workbench-recycle`。

## 防误操作与网页实时预览

- 修改中英文标题、ImageKit 地址或选择待添加的视频后，若直接关闭编辑器、切换版本或进入其他操作，工作台会询问「继续编辑／放弃修改／保存并继续」（仅单一文字草稿可以直接保存）。
- 右侧「发布与预览」中的「本地网页预览」会打开本地网站正确的分类，并滚动定位目标作品；**不会自动播放视频**。
- 本地工作台 `5190` 保存 3:4 封面或播放器海报后，通过受限的本机通知通道让已打开的 `5174` 预览页仅更新**对应图片**，不重载整页或打断播放器。作品库缩略图使用稳定版本 URL + 本地私有缓存，减少搜索和分类切换时的重复加载；保存/恢复封面后增加修订号，让新图及时可见。名称、排序等作品数据的修改会在安全时机刷新页面。
- 这个同步仅限本机预览，**不是 Netlify 发布**。线上仍由你决定何时提交 Git 和部署。
- 检查命令：`npm run check:workbench-navigation`、`npm run check:workbench-draft-focus`（草稿保护及键盘焦点），`npm run check:workbench-preview-sync`（隔离项目真实写入卡片封面及播放器海报，校验跨标签图片更新和零 CDN 请求）。

### 精确选帧、一次保存与等高按钮

- 「更换封面／海报」仅初始化当前本地视频会话，取得真实 fps，不抽取 12 张均匀时间采样帧。首次打开保留右侧原封面，不自动用 0 秒黑帧覆盖。
- 操作链路：播放或拖动左侧时间轴定位，按「首帧／上一帧／下一帧／尾帧」逐帧精调，或按住 ← / → 连续移动。播放器时间轴右侧显示毫秒，不再需要额外秒数输入；每次先即时移动本地视频，停止约 260ms 后才生成当前高清静帧，避免每次按键都阻塞在 FFmpeg。只保留**一个保存按钮**，从已选画面保存，尚未选帧时从当前播放时间先取帧再保存；旧图自动备份。
- ImageKit URL 单击编辑；固定前缀可复制但不能改，文件名后缀独立输入。同排保留「保存／取消」，Enter／Esc 为辅助快捷键，失焦不静默保存；切换作品会保护未保存草稿。
- 同排按钮保持统一高度、双轴居中、文字不折行。详情顶部作品切换按整个详情页精确居中；首帧／尾帧是普通按钮，不再默认高亮。详见 `docs/设计规范.md` 的「本地工作台桌面交互美学约束」。
- 回归 `npm run check:workbench-fast-jog`、`npm run check:workbench-phase3`、`npm run check:workbench-icon-alignment`、`npm run check:workbench-precision-frames`、`npm run check:workbench-navigation`、`npm run check:workbench-draft-focus`、`node scripts/check-cover-studio-legacy-version.mjs`。公开作品集网站手机版不受影响。

## 前端维护与视觉回归

- 工作台基础样式保留在 `tools/cover-studio/style.css`；近期新增作品、详情上下文、ImageKit、排序撤销等增强样式分离到 `tools/cover-studio/workbench-enhancements.css`，并在基础样式之后加载。不要随意颠倒加载顺序。
- `app.js` 的旧工作流 busy 同步现在不再改变作品库、作品详情和各个独立对话框的控件状态。各模块自行管理按钮禁用、提交和草稿状态；不要重新引入全局按钮禁用与启用。
- `npm run check:workbench-phase3`：用隔离项目在 1440×900、1280×720、1000×750 桌面视口检查导航箭头与页码双轴居中、详情两栏不重叠、新增弹窗不越界、纯黑预览底图以及增强样式可加载。
- `npm run check:workbench-simple-versions`：隔离核验自动命名 C 版本、可选自定义名称、单个版本重命名、共享作品名称、未保存 MP4 提醒、图片私有缓存和键盘取消；不操作正式素材。新建作品页底部进度提示会说明当前缺少 MP4、选帧还是标题，避免按钮灰掉却不知道原因。
- 保留 `check:workbench-ux`、`check:workbench-import-ui`、`check:workbench-icon-alignment`、`check:workbench-draft-focus` 和 `check:workbench-full-flow` 作为功能回归。只在隔离副本上写测试作品，不修改正式作品数据。
- 当前布局针对至少 921px 的桌面浏览器；改变按钮、标题、弹窗尺寸后，应重新运行布局与图标居中检查，而不是直接叠加新的 `!important` 覆盖。

## 保存和安全规则

**3:4 卡片封面**与**播放器原比例海报**是两个独立文件。保存只更换选中的一种，不改变 MP4、ImageKit URL、其他版本或精选顺序。 保存完成后工作台自动重新读取本地项目和图片；保存期间不能关闭编辑面板或切换版本，避免刷新被中断。工作台验证作品 ID、版本、时间点及原文件，备份旧图和修订记录后才更新。

默认 3:4 选帧使用完整画面与模糊背景，不暴露多余的裁切切换；播放器海报始终保留真实画幅。两种操作都在同一个宽屏编辑工作区内完成，不需要跳页、下载临时文件或多次勾选确认。

播放器由本机 `GET /project-video/:作品ID/:版本ID` 分段读取通过路径校验的 MP4，不访问 ImageKit。可播放、拖动视频时间轴、按实际帧率逐帧，播放时间显示毫秒，停止操作后才提取最新高清预览。个别浏览器不支持的视频编码，仍可用 FFmpeg 指定秒数取帧或直接导入图片。

## 旧封面历史与一键恢复

- 两种封面有各自的「历史」入口；播放器海报的备份还按 A/B/C **视频版本**分别管理。没有历史时会显示「还没有可恢复的旧图」。
- **每部作品的 3:4 旧封面最多保留 3 张**；**每个视频版本的原比例海报旧图最多保留 3 张**。当前正在使用的图片不计入；超额时自动删最旧备份图与对应 JSON，恢复前也会备份现用图。
- 历史面板左侧是**当前使用**的图片，右侧是**将要恢复**的旧图，下方可按日期切换版本。点击「恢复」即可替换，无需打开 Finder 或下载。
- **恢复前仍然会备份当前图片**。因此恢复错了，还能从历史中选择最近一条再恢复回来。
- 多窗口改动产生的过期恢复会被拒绝；跨作品、跨 A/B 版本、画幅不匹配、无效备份都无法恢复。
- 3:4 备份在 `.cover-studio/project-revisions/cover-history/<作品ID>/`，原比例海报在 `.cover-studio/project-revisions/poster-history/<作品ID>/`。历史界面仅显示图片、日期和操作说明，不暴露 UUID 文件名。
- 恢复只替换选中的封面，不修改 MP4、ImageKit、分类和其他视频版本。

## 视频版本和发布边界

**新建作品与历史作品均支持在详情页添加视频版本**。历史作品的新增版本和主视频名称分别记录于 `src/data/legacy-video-variants.json` 与 `src/data/legacy-main-version-labels.json`，不会为了增加 B/C 版本而迁移或覆盖原有 MP4；每部作品最多 8 个版本（含主版本）。

历史作品线上链接位于 `src/data/legacy-imagekit-urls.json`；新作品及其多个视频版本链接在 `src/data/auto-projects.json`。需要线上播放的视频，须先上传 ImageKit，再在对应版本填写地址；仅本地预览和保存不需要上传。**本地保存 ≠ 上传 ImageKit ≠ 提交 Git ≠ 部署 Netlify**。

## 排序、文件与恢复

- 正式 3:4 封面：`assets/images/project-covers/<category>/<English Stem>.webp`。
- 正式播放器海报：`assets/images/player-posters/<category>/<MP4 English Stem>.webp`。
- 封面替换、名称、排序和版本等历史存于 `.cover-studio/project-revisions/`，这是回滚资料，**不要当缓存删除**。
- 精选和四分类作品顺序互相独立；搜索结果禁止拖动，避免漏掉隐藏作品。
- 旧式单独排序、导出和手工关联的实现暂保留兼容，但**已从日常导航中移除**，避免重复入口。

## 本地空间维护（可选）

多个封面编辑会话会生成同内容的临时 MP4。工作台已支持 SHA-256 去重，新导入视频自动共享只读源数据，而每个会话原路径不变。若想查看占用，终端执行 `npm run covers:storage:scan`；需核对文件是否完整时执行 `npm run covers:storage:verify`。**不要直接清空** `.cover-studio/sessions/`、`exports/` 或 `project-revisions/`；其中可能含未保存的选帧与可恢复的历史。技术原理及独立恢复命令见 [本地封面工作流](./本地封面工作流.md#本地会话视频去重与恢复第二阶段)。

工作台的作品库卡片、详情页双封面、选帧对比、新建作品预览使用相同的**纯黑色背景**；不同宽高比只用黑色留边，不强行拉伸或裁切源图。
