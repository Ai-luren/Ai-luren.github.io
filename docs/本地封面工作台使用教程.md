# 本地封面工作台使用教程

这份教程说明如何为作品视频挑选、调整并导出封面。工作台只在本机运行，不会因为视频文件更新而自动打开，也不会自动决定或替换封面。

## 1. 启动工作台

1. 打开终端，进入本地项目根目录。可以先输入 `cd `，再把 Finder 中的「个人网页作品集」文件夹拖到终端并按回车。

2. 启动工具：

   ```bash
   npm run covers
   ```

3. 在浏览器打开 <http://127.0.0.1:5190/>。

如果页面提示 FFmpeg 不可用，需要先在 Mac 安装 `ffmpeg`（它同时提供 `ffprobe`），然后重新启动工作台。处理视频期间保持终端窗口运行；完成后关闭该终端进程即可停止本地服务。

## 2. 从视频制作封面

### 导入视频并挑选画面

1. 点击「选择本地 MP4」，选择电脑中的视频。原视频会复制到本地工作区，原文件不会移动或修改。
2. 等待视频信息和 12 张候选画面出现。工具会显示视频时长、分辨率和画幅。
3. 点击候选画面查看预览。候选帧只是供你挑选，工具不会默认选中任何一帧。
4. 如果候选帧里没有理想画面，在「时间点（秒）」输入时间并点击「提取该时间点」。也可以拖动时间轴，或使用「−1 帧」「+1 帧」微调。

### 调整 3:4 构图

1. 选择 **Cover / 裁切填满**，让画面铺满封面；或者选择 **Contain Blur / 完整画面**，保留完整原画面并用模糊背景补满画布。
2. 在预览中拖动画面，或使用水平、垂直位置滑块调整主体位置。需要重新开始时，点击「恢复居中」。
3. 放大检查人物、产品、品牌 Logo 和画面文字是否完整。横屏画面使用 Cover 时裁切较多，可尝试 Contain Blur。

### 确认导出

检查完成后，点击「确认使用此封面并导出」。只有点击这个按钮后，才会生成 **900×1200、3:4 的 WebP**。页面会显示导出预览、文件位置、体积和下载链接。

之后若更换画面、处理模式或构图位置，需要重新确认导出，确保最终文件与当前预览一致。导出封面本身不会修改作品数据。

## 3. 关联到已有作品

1. 在「关联对应作品」中选择目标作品，先核对标题和当前封面。
2. 检查刚导出的封面，然后勾选确认框。
3. 点击「确认替换此作品封面」。新封面会以新文件名加入项目；旧封面文件保留。
4. 刷新作品库页面确认结果。原有 8 件首页精选作品受保护，工作台不允许替换它们的封面。

如果当前不想关联，可以只导出 WebP，稍后再处理。导入现成 JPG、PNG 或 WebP 时，可跳过视频抽帧；仍需调整预览并明确确认导出。

## 4. 新作品的处理顺序

新作品还没有出现在作品列表时：

1. 在工作台选视频并导出封面。
2. 登记作品的标题、分类、视频地址和封面信息到项目作品数据中。
3. 回到工作台点击「刷新作品列表」，选择新作品并按上述步骤确认关联。

工具不会自动创建作品条目，也不会从视频中推断标题、类别或奖项。

## 5. 文件保存位置与注意事项

- 导入视频副本、候选帧、手动提取画面和导出记录保存在项目根目录的 `.cover-studio/`，该目录不进入 Git 和网站构建。
- 确认关联的封面文件放在 `assets/images/project-covers/custom/`；对应关系记录在 `src/data/project-cover-overrides.json`。
- 原视频与已有封面不会被覆盖。每次导出都会生成新文件，工作台不会自动清理本地工作区。
- 目前单个导入文件上限为 2GB，视频输入格式为 MP4。支持横屏、竖屏等比例。
- 上传、抽帧和导出都在本机完成，不需要 API Key 或云端视频服务。

## 常见情况

**打开地址失败**：确认 `npm run covers` 仍在运行，并访问 `http://127.0.0.1:5190/`。

**没有候选画面**：等待导入进度完成；若终端显示 FFmpeg 错误，确认本机可运行 `ffmpeg` 和 `ffprobe`。

**按钮无法导出**：先点击一张候选画面，或手动提取一个时间点，再检查预览构图。

**替换后网页没变化**：重新加载作品库；确认关联步骤已完成，并检查选中的作品是否属于受保护的 8 件首页精选。
