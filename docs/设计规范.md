# 个人作品集设计规范

本文是公开作品集（首页与全部作品页）唯一持续生效的视觉与交互规范，记录当前生产构建中已落地的规则，作为后续新增组件的复用依据。维护文档与历史快照的分层参见 [文档索引](./文档索引.md)。它描述实际生效的页面，不要求把语义不同的页面强行做成同一外观。Token 真值位于 `src/styles/apple-system.css` 与 `src/styles/card-surfaces.css`；组件排版和响应式变体由对应组件样式负责。日期化验收和审计文件只保留历史测试结果或建议，不覆盖本文与当前源码。

## 设计方向

作品和影像优先，界面采用中性深色、清晰层级与克制动效。首页的 Hero 与滚动视频保留独立的叙事样式；内容区以可读性和一致的媒体边界为主。不同页面在筛选控件、导航形态和浏览行为上可以保留符合用途的差异；首页精选与全部作品使用同一作品卡媒体比例和信息节奏。

## 字体与文字层级

字体栈由 `--font-display`、`--font-body` 和 `--font-mono` 提供：系统无衬线字体用于标题与正文，等宽字体用于编号、标签和技术性元信息。

| 语义角色 | 实际规则 |
|---|---|
| Hero 标题 | 独立展示层级，最终规则在 `index.html` / `apple-system.css`；使用响应式 clamp、紧凑行高和自然换行。`--type-hero` 是兼容 Token，具体 Hero 规则仍由专属选择器控制。 |
| 页面 H1 | `.page-title` 消费 `--page-title-size/weight/line-height/letter-spacing`。桌面最大 64px；作品库 390px 手机端 computed 为 39px。独立页面标题不附加章节蓝线。 |
| 首页章节 H2 | `.section-title` 消费 `--section-title-*`。1440px 为 64px/1.02，1024px 为约 49.15px/1.02，390px 为 39px/1.02。 |
| 专业实力的四个同级子标题 | 获奖、平台、自媒体与 AI Lab 使用同一字号 Token：1440px 为 43.2px、1024px 为 36px、390px 为 31.2px。均严格小于一级「专业实力」标题；手机端 AI 平台创作者卡片的内部 H3 进一步降为 24–28px。 |
| 项目卡片标题 | `--project-card-title-*`：桌面 16px、600、1.4；手机 14px、500、1.45。首页和作品库共享。 |

移动端两列作品卡片标题维持既有 14px，不为容纳长标题而整体缩小字号。英文品牌名加中文标题（如 `FormFunk 餐具创意广告`）在 `ProjectCard` 中统一标记混排语义，通过 `word-break: keep-all` 优先在语言边界折行，`overflow-wrap:anywhere` 作为小屏安全回退；禁止形成末行孤字、截断项目名、拉高独立卡片或打乱同排分类标签基线。纯中文／英文名称不受该规则影响，`check:work-card-a-plus` 跨两页、中英及四种宽度校验。
| 正文 | 通用正文基准 `--type-body: 14px`；模块可以按阅读场景设置局部字号与行高。关于我正文桌面约 16–17px、行高 1.72，手机 16px、行高 1.75。 |
| 辅助说明 | `--apple-secondary` 为主要辅助色；项目说明使用 `--project-card-detail-*`，12px、400、1.55。更弱元信息使用 `--apple-tertiary`。 |

中英文共用同一语义 Token。英文标题、项目名称和正文自然换行；项目卡片允许 `overflow-wrap:anywhere`，奖项说明可换行，不以缩小字体或强制单行解决长度。中文保持自然断行。标签和按钮避免超出容器；英文菜单标签按导航可用宽度布局。

## 色彩 Token

| Token | 当前值 | 用途 |
|---|---|---|
| `--apple-bg` | `#000` | 首页深色叙事底色。 |
| `--portfolio-page-surface` | `#0b0c0f` | 独立作品库等中性深黑页面底色。 |
| `--portfolio-modal-solid` | `#0c0c0d` | 禁用模糊或不支持模糊时的不透明弹层底色。 |
| `--apple-text` | `#f5f5f7` | 主文字。 |
| `--apple-secondary` | `#a1a1a6` | 正文辅助信息、项目奖项说明。 |
| `--apple-tertiary` | `#86868b` | 弱提示、标签和次级元信息。 |
| `--apple-blue` | `#2997ff` | 主要操作提示、键盘焦点、项目说明竖线。 |
| `--apple-hairline` | `rgba(255,255,255,.14)` | 常规细分隔线与边框。 |
| `--apple-hairline-soft` | `rgba(255,255,255,.09)` | 弱分隔线。 |

蓝色只承担明确的交互或信息标记角色，不作为大面积背景装饰。Hero 等少数既有特效可使用专属叙事色，不据此扩展普通内容区的配色。

Hero CTA 只有一套视觉契约：语义 Token 在 `src/styles/apple-system.css` 的 `--hero-cta-*`、`--hero-primary-*`、`--hero-secondary-*` 中定义，按钮几何、材质、交互与断点只由 `src/components/HeroActions.css` 实现。HTML 内不能再加高优先级按钮覆盖；全局也不能另设主 CTA 的强制颜色或尺寸。蓝色「查看作品」仍是唯一主操作，次操作「合作联系」使用中性深灰高遮蔽玻璃（92%）、亮白文字和细边框；绝不在动态视频上采用透明灰字。**双 CTA 不允许各自发光/投影、上浮或按压缩放**，hover/press 统一仅改变按钮背景或细边框（180ms），保留键盘 focus-visible 蓝色 2px 焦点环；CTA 常态实心蓝采用 `#0071e3`、悬浮 `#0066cc`，白色 15–16px 字的对比度分别约 4.70:1 / 5.57:1（WCAG AA），亮色 `#2997ff` 仅继续作为系统点缀/焦点色，禁止用在白字实心 CTA 背景。两者同高、同圆角、同字重，桌面 48px、手机 46px；手机宽度 138/130px，桌面 152/136px。副标题使用 `--hero-subtitle-color` 提高可读性。`npm run check:hero-conversion` 验证中英文、按钮对齐、尺寸及极端黑白视频底色上的文字对比度（至少 7:1）。

## 线条的语义

- **章节标题装饰线**：首页章节和影响力子章节下方的蓝色短线已移除，不用其他线条替代。页面 H1 同样不附加装饰线。`--apple-blue` 仍可用于主操作、键盘焦点及有语义的作品说明标记；不要把这些功能色误当成章节装饰。
- **作品说明竖线**：项目卡片 `.comet-archive__details::before` 与作品播放器详情 `.cinema-player__caption p::before` 共享 `--project-card-marker-*` 和 `--project-card-detail-gap`：蓝线 2×14px、左侧与标题齐平、第一行文字盒子上沿下移 2px、文字向右缩进 12px（2px 线＋10px 间距）。桌面、手机及中英文遵循相同规则；多行说明的蓝线不随文本增高或纵向居中到整个段落。它标示奖项或分类说明，与章节装饰线无关。
- **选中状态线**：导航和筛选器自身状态。桌面主导航用文字下方的 1px 中性白线；移动作品分类 Tab 用当前文字色的 1px 短线。首页与作品库的移动菜单当前项均使用文字细下划线（1px，距字 5px），不恢复旧白色圆点或容器底边线；全部导航选中、悬浮与焦点状态文字始终处于同一高度，不做 1px 上移动画。它们表示当前选择，不使用章节蓝线。

## 圆角与媒体比例

共享圆角由 `src/styles/card-surfaces.css` 定义：

| Token | 值 | 语义 |
|---|---:|---|
| `--portfolio-panel-radius` | 24px | 大面板、桌面玻璃卡片、导航胶囊。 |
| `--portfolio-content-radius` | 18px | A+ 作品卡外边界、内容媒体、桌面视频画面和获奖查看器原图。 |
| `--portfolio-tile-radius` | 12px | 紧凑重复 tile。 |
| `--portfolio-control-radius` | 999px | 胶囊操作控件。 |
| `--portfolio-icon-radius` | 50% | 圆形图标按钮、头像。 |

特殊上下文保留组件规则：播放器手机画面圆角为 16px；关于我与合作联系玻璃卡片手机端为 20px；移动作品分类 Tab 无圆角。不要把上述语义强制改成同一个值。

奖项画廊缩略图是紧凑媒体 tile，使用 12px `--portfolio-tile-radius`；打开查看器后展示原比例图片，桌面使用 18px 内容圆角，手机限于 14–16px。不要将缩略图规则套到查看器原图上。

封面比例契约：

- 首页精选和 `works.html`：全部尺寸统一使用 `--portfolio-work-cover-ratio: 3 / 4`，原始作品封面保持既有 `cover / contain` 规则。
- **A+ 一体化作品卡**：首页精选和全部作品均使用 ProjectCard + UnifiedWorkCard.css 的同一玻璃外框，封面、标题、分类都属于整张可点击卡片。鼠标悬浮时只加强外边框和外阴影，不在封面上叠第二层阴影、黑色蒙版或缩放。键盘焦点显示在整个外框上。
- **防回退检查**：运行 `npm run check:work-card-a-plus`，分别对中英文、320/390/721/1440px 与首页/作品库检查整卡玻璃层、封面顺序、标题与分类的紧凑排版、圆形播放按钮的 SVG 几何居中和悬浮时不出现第二层图片阴影。
- **紧凑信息区**：桌面外框内边距 7px、图片到标题 9px、标题到分类基础间距 4px；手机外框内边距 6px、图片到标题 7px、标题到分类基础间距 4px。移除强制双行标题高度；同排分类的底边对齐，英文自然换行。手机断点仍为 720px。
- **圆角与表面**：A+ 外框桌面 18px、手机 14px，内层 3:4 图片桌面 12px、手机 9px；图片自身无单独边框、阴影或模糊。外框继承 `--portfolio-glass-surface`、`--portfolio-glass-blur` 和共享作品卡阴影 Tokens。首页移动分页与 Works 分类过滤保留各自布局。
- **图片与播放图标**：封面底色一致为近黑色 #020203；保持 3:4 和现有 cover / contain 策略。封面右下角一个圆形播放图标（桌面直径 36px、手机 30px），SVG 三角形的填充质心在 (12,12)，不使用 margin 人为偏移；不可播放则保留「待上传 / Pending upload」文字。没有嵌套第二个点击按钮，继续打开现有 CinemaPlayer，未播放不提前请求 MP4。
- 获奖图片查看器按原图自然比例约束视口，不套用视频作品的 3:4 卡片比例。
- 图片保持完整内容；需填充时必须遵循组件现有的媒体处理规则，不擅自改变数据或裁切意图。

## 面板、玻璃与阴影

共享表面 Token：

- 面板：`--portfolio-panel-surface: rgba(28,28,30,.72)`、`--portfolio-panel-border: rgba(255,255,255,.14)`、`--portfolio-panel-blur: blur(22px) saturate(1.08)`、`--portfolio-panel-shadow`。
- 内容媒体：`--portfolio-content-surface: rgba(0,0,0,.58)`、`--portfolio-content-border: rgba(255,255,255,.18)`、`--portfolio-content-shadow`；媒体本身不叠第二层模糊。
- 紧凑 tile：`--portfolio-tile-surface: rgba(255,255,255,.05)`、`--portfolio-tile-border: rgba(255,255,255,.09)`；Hover 表面为 `--portfolio-tile-surface-hover`。
- 弹层遮罩：`--portfolio-modal-surface: rgba(12,12,13,.9)`、`--portfolio-modal-blur: blur(28px) saturate(1.02)`；降级使用 `--portfolio-modal-solid`。

面板只使用一层材质，不重复嵌套玻璃。**Cinematic Content Glass** 是信息面板的唯一共享材质：`--portfolio-glass-surface: rgba(26,27,31,.82)`、`--portfolio-glass-blur: blur(22px) saturate(1.04)`。适用于三块影响力面板（获奖、平台超创、自媒体）、实验室索引、关于我／合作联系、Hero 证明卡及移动作品容器，由 `src/styles/card-surfaces.css` 将角色绑定至对应选择器。**Chrome Glass**（导航胶囊）继续使用较轻的 `--portfolio-panel-surface: rgba(28,28,30,.72)` 和 `--portfolio-panel-blur`；**Modal Scrim**（菜单／播放器／账号资料遮罩）继续使用更深的 `--portfolio-modal-surface: rgba(12,12,13,.9)` 与 28px 模糊，账号资料与获奖弹层的内容区域保持透明（不叠第二层玻璃），需要不透明卡片时才使用 `--portfolio-modal-panel-surface: #191a1e`。背景材质以 Token 为准，`index.html` 不应对阅读面板新增实色或禁用模糊的强制覆盖。边框、阴影、面板圆角仍统一复用 `--portfolio-card-*`，Hero 证明卡沿用 18px 内容圆角；封面、截图、视频本体不叠加第二层模糊。

`prefers-reduced-transparency: reduce` 与不支持 `backdrop-filter` 时采用不透明中性深色背景并关闭模糊；不以 `prefers-reduced-motion` 代替透明度降级。材质降级也分三种语义：Chrome Glass 使用 `--portfolio-panel-solid`，Cinematic Content Glass 使用 `--portfolio-glass-solid`（目前都为 `#1c1c1e`），仅全屏遮罩使用 `--portfolio-modal-solid`（`#0c0c0d`）。正常模式的原有透明度、模糊、阴影和圆角保持不变。所有主要阅读面板的无模糊降级统一在 `src/styles/card-surfaces.css` 声明；导航及获奖查看器的降级由 `src/styles/navigation.css` 控制，账号资料遮罩沿用自身查看器降级。不得把导航使用的材质错误地替换成全屏遮罩色。清理材质规则时只删除确认不再有 DOM 消费者的历史选择器，不调整播放器、媒体截图等内容表面。

生产构建的 `vite.config.js` 当前禁用 CSS minify：默认压缩器会移除 Edge 所需的无前缀 `backdrop-filter`。调整压缩策略前必须核对 `dist/assets/*.css` 和 Edge 中的 computed style。

## 弹窗动效契约

作品播放器、获奖荣誉、AI 自媒体账号资料使用同一进入／退出节奏：`--apple-duration-modal: 260ms`、`--apple-duration-modal-exit: 220ms`、`--apple-ease` 缓动，内容区有 8px 以内的轻微位移。仅透明度和内容 transform 参与过渡；共享玻璃导航不能缩放/位移，Backdrop 的模糊半径和媒体布局不参与动画。退出前保留模态层，动画后再卸载并恢复源触发器焦点、滚动和 inert 状态；原生影片退出时立即停止媒体，不允许等待动画结束才停止播放。连续点击关闭只执行一次，动画未完成时允许关闭，`prefers-reduced-motion: reduce` 时直接关闭。运行 `npm run check:modal-motion` 验证手机/平板/桌面、正常/减少动态效果及零 ImageKit 流量。

## 按钮、链接与交互状态

按语义保留控件差异：主行动按钮、文字链接、胶囊筛选、圆形图标按钮和箭头不是同一种外观。导航在 761px 起统一显示四项横向文字栏目（含平板竖屏）；760px 及以下使用折叠菜单。首页与全部作品页共用同一玻璃胶囊导航及语言切换控件。 语言切换采用 B+++ 轻玻璃双分段：桌面直接显示「中文 / EN」，手机端显示更紧凑的「中 / EN」；被选项使用 200ms 的中性浅玻璃滑块；桌面宽 100px、高 38px，手机宽 94px、视觉胶囊高 40px（内部透明按钮触控热区高 44px），与 44px 圆形菜单按钮共用中性玻璃材质。桌面打开/关闭详情查看器时，语言控件横向滑移 58px，关闭按钮淡入/缩放，与弹窗生命周期同步反向收起；弹窗导航本体不变形，手机「＝ ↔ ×」动画不受影响。该组件复用到首页、全部作品、播放器、获奖及账号资料查看器，保持一份语言状态、键盘可访问的独立按钮和 aria-pressed；760px 及以下保留透明导航与圆形菜单，不更改主导航结构。 跨越 760/761px 断点时，正在打开的手机菜单必须立即关闭并释放滚动锁定/背景 inert；菜单作为模态层，Tab 不得跳出弹窗，关闭后聚焦有效入口。作品库桌面筛选为胶囊，手机端为文字 Tab。

- 默认态使用对应语义表面、描边和主次文字色。
- Hover 提升文字/表面/描边对比；动效使用 `--apple-duration-control: 180ms` 和 `--apple-ease: cubic-bezier(.22,1,.36,1)`。
- `:focus-visible` 使用 2px `--apple-blue` 外框并留出 offset；不可移除键盘焦点。
- Active/Pressed 使用略高对比的控件表面。禁用箭头降低不透明度且不可操作。
- 触控按钮最小热区通常为 44×44px；尺寸较小的图形由热区容器承载。
- Floating Dock 固定图标占位容器，图标与提示以悬浮/transform 反馈显示，不能改变外层玻璃卡片尺寸；触屏不依赖 Hover。

## 工作台与公开网页的职责边界

公开网页（首页与全部作品）使用本文件的 Token 与导航、卡片、弹窗规则；桌面专用作品工作台不套用公开网页手机断点。工作台的按钮几何、版本/封面/海报编辑与安全操作只有 [本地工作台技术维护](./本地封面工作流.md) 负责，[工作台使用指南](./本地封面工作台使用教程.md) 面向实际操作。不得在此处复制第二份工作台规范。

## 统一导航的不可破坏原则

首页和全部作品页的一级导航固定为四项：**精选作品｜全部作品｜专业实力｜联系**（英文为 Featured｜All Work｜Expertise｜Contact）。「专业实力」聚合获奖荣誉、平台超创、自媒体和 AI Lab（技术实践）四个子模块；AI Lab 保留原锚点和项目链接，只降为子章节，不另建一级导航或 Hover 下拉。四项入口在桌面导航、首页手机菜单、作品库菜单中统一。首页与 `works.html` 手机菜单使用同一套 **4 条主导航大字纵排 + 底部 4 个社交文字链接 + 版权** 的信息架构与视觉 Token；主导航继续保持四条，不引入搜索、营销模块或子菜单。菜单顶部保留同款玻璃导航胶囊、语言切换、圆形关闭按钮（首页保留既有 `＝→×` 动画）。底部社媒菜单按 **抖音、小红书 / 飞书、GitHub** 两行两列排列，链接由 `src/navigation/socialProfiles.js` 唯一维护（不影响页脚 Dock 的排列），HTML/React 统一由 `src/components/MobileMenuSocialLinks.jsx` 渲染，社交区与四条一级导航严格区分。触屏外链仍遵守已有二次确认规范。**首页和 Works 展开菜单不能分别定义第二套字号、背景或社媒入口。**旧的奖项/平台/自媒体/Lab 深链接保持有效；对应区域滚动时都选中「专业实力」，联系方式/关于我区域选中「联系」，全局同时只能有一个当前项下划线。选中状态由页面滚动监听统一管理，不应在 React 组件中另写平行的滚动监听。用户点击一级导航触发平滑滚动时，目的地选中线一直保持至本次滚动结束；途经中间章节的 IntersectionObserver 仍可更新背景，但不能抢走导航选中状态。用户滚轮、触摸或滚动键主动中断时解除临时锁定，并恢复正常滚动高亮。首次加载时 GSAP ScrollTrigger 刷新可能提前触发 `scrollend`；若点击「专业实力」尚未到达目标区域，只允许自动恢复这次平滑滚动一次，不能永久锁住选中线或覆盖用户主动中断。**生产构建**回归须同时检查下划线及目标区域真正进入视口：`node scripts/checks/site/check-desktop-primary-navigation.mjs`、`npm run check:nav-scroll`、`npm run check:home-scroll`。

**跨页跳转语义（2026-11-16 已修复，禁止回退）**：作品库导航中标为「首页 / Home」的品牌链接始终指向 `./index.html#top`，点击必须抵达 Hero 顶部 `scrollY≈0`，不得将它改为 `history.back()` 或恢复访问作品库前的旧影片帧。**浏览器本身的后退/前进**仍独立保留阅读位置和影片进度。作品库手机菜单和桌面导航中的「精选作品」「专业实力」「联系」分别前往 `index.html#projects`、`#recognition`、`#contact`；React 作品内容挂载完毕后再做初始锚点对齐，不能在浏览器早期 `load` 阶段把 `initialHashAligned` 提前锁定。**`#recognition` 必须定位其本级 `.section-intro`**，手机端只允许 `#impact-awards` / `#impact-programs` / `#impact-reach` 使用 `.impact-evidence-label h2` 子级锚点，禁止意外把「专业实力」定位到「AI 获奖荣誉」。锚点统一位于浮动导航下方约 88px；末尾「联系」是最终合作卡片，当页尾自然阻止其卡顶对齐时须将整张卡片完整显示，不人为追加一整屏空白。React / ScrollTrigger 完成异步排版后可进行无用户输入时的一次幂等矫正；用户滚轮、触摸和键盘输入永远优先。保持 `npm run check:cross-page-nav`（320/390/760/1440px × 中英文 × 4 个目标）、`check:page-handoff`、`check:poster-return`、`check:home-scroll` 的回归。

**全站只有一套导航视觉与交互契约。** 首页主导航、作品库导航、AI 获奖图片查看器、作品详情播放器和 AI 自媒体账号资料查看器，都使用共享的导航胶囊样式。任何新弹窗或详情查看器应当直接复用 `src/components/CinemaNavigation.jsx`；不得在弹窗内另造标题栏、语言切换按钮、关闭按钮、返回胶囊或相似但不相同的导航组件。

- 弹窗只显示 **一条**共享导航：头像与品牌、语言切换和标准关闭按钮。原页面导航应隐藏，背景不可聚焦。
- 模态边界必须覆盖共享导航与内容本体。原生 `dialog.showModal()` 使用浏览器模态语义；自定义获奖与自媒体查看器在最外层设置 `role="dialog"`、`aria-modal="true"` 和标题关联 `aria-labelledby`，内部内容容器不能另设第二个对话框；视觉容器的 `role="presentation"` 不可替代模态语义。
- 弹窗内容（例如「小红书」、奖项标题、作品名称）属于内容区，不能伪装成第二条导航。查看器的关闭按钮、语言状态、焦点管理、Esc 关闭与返回触发点的逻辑必须回归验证。
- 新增查看器时，先检索 `CinemaNavigation`、`src/styles/navigation.css` 以及既有查看器实现，**复用而非复制**。除非统一修改共享导航本身，否则禁止新增 `*-dialog-header` / 私有关闭按钮来替代导航。
- 键盘焦点下，获奖卡片、自媒体账号资料和保存二维码复用蓝色 `--apple-blue` 焦点环；鼠标 Hover 仍沿用组件反馈。关闭弹窗后焦点返回触发元素，背景从 inert 恢复。作品播放器、获奖查看器、账号资料及作品库折叠菜单均要满足 Esc 关闭、Tab 不逸出。减少动态效果时允许显示更高对比度的焦点轮廓。
- AI 自媒体手机端按抖音、小红书、快手、视频号顺序紧凑排列；动作顺序为「查看资料」再「访问主页」（没有主页链接的视频号只显示前者）。
- 每次修改全局 Token、影响力模块、作品卡或导航，必须运行 `npm run check:social-media` 与相关的作品、导航回归测试，不得只检查改动模块。


## 影院与详情查看器导航细则

以下属于**公开作品集**的共用查看器，不是本地工作台的作品间导航。共用入口为 `src/components/CinemaNavigation.jsx`、`src/styles/navigation.css`，章节相对链接由 `src/navigation/links.js` 维护。

- **统一导航几何**：桌面玻璃胶囊最大宽度 980px、顶部 14px、高度 58px；手机左右内边距 12px、高度 56px，并计入 safe-area。首页 Hero 上方及弹层采用 `--portfolio-panel-surface` 半透明导航；首页进入正文后与 `works.html` 列表页统一采用 `--portfolio-panel-scrolled-surface` 提高文字背景对比度（减少透明度模式使用实底）；两页相同上下文不得显示不同背景透明度。首页保留静态 header，作品库、影院、获奖、账号资料、AI Lab 复用同一组导航规则。品牌名从 `src/i18n/dictionary.js` 的 `brand.name` 获取；品牌文字不得被头像圆形裁切容器遮挡。普通作品库保留 A+「首页 / Home」返回首屏；弹窗为头像／品牌＋语言＋关闭。
- **模态与焦点**：影院以原生 `dialog.showModal()` 进入 top layer，底层保持 inert；影院时隐藏首页 header／作品库导航，退出后恢复。获奖查看器采用固定背景伪元素，避免滚动祖先上的模糊使导航跟随图片移动；`scrollbar-gutter: stable` 防止锁滚动时导航偏移。所有查看器的 Tab/Esc/关闭、焦点回到触发卡片、背景滚动与减弱动画偏好均需回归。
- **影院箭头和短屏布局**：桌面视频两侧同时具备至少 80px 空间才将同一对 48px 箭头放在画面两侧，否则移到信息区下方；手机使用“上一部轻量箭头／序号／下一部轻量箭头”，没有重复的「全部作品」入口。禁止重复箭头或覆盖视频原生控制条。桌面媒体尺寸仍扣除导航、标题和 safe-area；手机媒体按宽高比独立计算，标题与操作区自然排列，竖版长视频可在同一弹窗中滚动，不因强行单屏装下所有内容而过度缩小。
- **获奖查看器**：按原图 `naturalWidth / naturalHeight` 显示，不继承视频作品 3:4 卡片高度。桌面切换箭头距图片 20px；手机位于说明下方；桌面图片圆角 18px、手机 16px，不叠第二层黑框。只有「海螺 AI 动物跳水」右侧接缝可在该查看器定向裁切；其他图片及图内主办方证据保持完整。
- **返回语义**：影院详情不再提供重复的「全部作品 / All Work」按钮。顶部 × 或 Esc 统一负责关闭影片并回到打开前的位置；从作品库打开还原筛选、URL 与滚动位置，从首页精选打开则返回精选作品区域。进入全部作品使用站点现有一级导航／精选区入口，而非播放器内部二次导航。`popstate` 应按已有浏览器历史关闭影院。
- **其他详情**：账号资料左右切换复用共享导航，不因分页重建；AI 实验室项目切换与粗指针站外二次确认见 [AI 实验室与外链维护](./AI实验室与外链维护.md)。影院换片、媒体加载状态及首尾禁用见 [播放器媒体维护](./播放器媒体维护.md)。

**回归**：`node scripts/checks/site/check-unified-navigation.mjs`、`node scripts/checks/site/check-cinema-navigation.mjs`、`node scripts/checks/site/check-cinema-layout.mjs`、`node scripts/checks/site/check-modal-material-fallback.mjs`、`npm run check:poster-return`、`npm run check:motion-polish`；检查 360、375、393、430、1280、1440、1920px 的导航、焦点和短视口。

## 布局与响应式策略

- 内容版心最大约 1220px；平板以可用宽度和安全边距收缩，手机主内容左右各约 16px。导航胶囊有独立的居中宽度约束，不改变正文版心。
- 首页精选桌面四列；手机采用连续八卡、四排两列，去掉外层玻璃框、侧箭头与分页指示，保留每张 A+ 卡片的共享材质。手机精选行距收敛到 12–16px，精选结束后的电影叙事间隔为 68–96px（按视口高度响应），保留八张作品和完整海报、不以折叠/轮播换取短页面。作品库桌面随宽度采用两、三、四列，手机双列。两页共用封面→标题→奖项／分类说明的阅读顺序。精选区不再展示冗余的「8 部代表作品／8 Featured Works」数量注释；「浏览全部作品／Browse All Work」仍作为主要作品库入口，桌面与标题同排并靠右对齐，手机紧跟「精选创作档案」主标题下一行左对齐（标题和链接同属一个动效组），卡片末尾不再重复入口。手机作品库只有 4 个分类 Tab（商业广告 / 创意短片 / 海外产品广告 / 视觉实验，不单列「全部」），均须提供至少 44×44px 的实际触控热区，320px 等窄屏允许自然排成两行。
- 首页精选不再以旧的三行 subgrid 把海报、标题和分类拆开对齐；整张 A+ 卡片按自然 DOM 顺序排列，同排分类信息的下沿对齐，长英文自然换行、不截断。手机仍是双列，但八张完整展示；按实际滚动距离解码后续封面，不预加载全部作品抢占 Hero 视频带宽；作品排序及播放器导航保持不变。
- AI 获奖荣誉、AI 平台超创和 AI 自媒体共用章节外层节奏：各自标题与说明在上，整宽玻璃面板在下；桌面与手机均保持这一顺序，版心内的标题到面板间距由共享影响力间距 Token 控制。三个面板内部仍按内容用途分别使用奖项网格、平台展示和自媒体紧凑账号布局。
- AI 平台超创的 8 个品牌 Logo 和创作者身份是静态展示：在一层 Cinematic Content Glass 内以桌面 4×2、手机 2×4 的紧凑分隔网格组织，每格 Logo 位于名称及身份左侧；不增加独立玻璃边框或虚假点击态。
- AI 获奖荣誉一次展示全部 8 张：≥1280px 八列，≤1279px 四列两排；手机只展示完整图片，点击后在查看器阅读标题与奖项。卡片区无需左右切换。获奖、播放器、AI 自媒体账号资料与 AI 实验室的前后切换统一由 `src/styles/navigation.css` 管理圆形 Ghost 箭头：常态无底框、显示 20px 同款 SVG，hover／focus-visible 出现柔和圆形背景与细框；普通查看器使用至少 44px 触控区域、获奖左右按钮 48px，计数器与焦点环保持一致。获奖放大查看保持单张原比例清晰主图，≥1100px 桌面旁边增加 8 张小图索引（直接切换，无独立第二套全屏大图）；**手机隐藏的缩略图不可参与 Tab 焦点循环**，焦点陷阱只收集布局中可见的实际控件（`getClientRects().length > 0`），关闭恢复触发器焦点；平板和手机维持原单图查看，短视口缩小缩略图避免裁切。不得恢复播放器的圆角方块或获奖常驻底框。
- 展示次序单独维护：获奖区按 MJ 官方优秀作品 → 未来 AI 设计大赛 → 联想 AI 比赛 → 海螺 AI 动物跳水 → 无限剧场小赛 → 海纳星火计划（小人国制作奶茶）→ 海纳星火计划（打工喵的一天）→ 影视级特效小赛。首页的 8 件精选由 `src/data/project-order.json` 的 `featured` 动态选择和排序；作品库由同文件的 `all` 独立控制，桌面、手机、中英文与播放器导航共享正确次序。首页最新四部优先保证制作质量和高清观感，而不是为了分类多样性提前旧作品；当前前四顺序为 FormFunk 创意广告 → MEXC 不用等了 → FormFunk 产品短片 → MEXC 会员权益，保留这些高质量近作且避免同品牌连续，`all` 列表绝不同步重排。作品库默认商业广告，只显示四个分类筛选按钮。运行 `npm run check:curated-order`。
- 获奖画廊包含赛事奖项、入围与公开展映，以「荣誉与展映 / AWARDS & SHOWCASES」概括；图片查看器保留完整中英文标题和说明。
- 奖项图片使用 `object-fit: contain`，不裁切；桌面和平板的图片、标题和说明左对齐，长英文自然换行。手机隐藏卡片文字，在图片查看器显示完整信息；焦点反馈不得改变卡片几何尺寸。
- AI 实验室作为「专业实力」中的次级内容区，标题字号低于一级「专业实力」，沿用编辑式列表结构与独立 #experiments 锚点，不统一成图片卡片。
- 四个同级子标题的左边缘统一与「专业实力」主标题对齐，不允许在平板和桌面给获奖、平台、自媒体三个标题额外添加 4px 左内边距。
- 四个子标题统一 `--expertise-subheading-size`（桌面约 34–40px、手机 26–30px），显著低于一级「专业实力」，且 AI 实验室与三组证据标题等权；它们到对应玻璃卡片的距离统一使用 `--expertise-title-panel-gap`：<=760px 为 20px，>=761px 为 28px。由 `--expertise-subheading-size` 表达共同的子标题语义；卡片内 H3 使用更低的 `--expertise-card-heading-size`（仅手机端）。实验室不再叠加列表 margin-top 与标题默认 margin-bottom。一级标题到第一子标题使用 `--expertise-main-subheading-gap`（手机 36px，桌面 44px）。
- 关于我与合作联系使用一体式玻璃卡：**移除显示性的「关于我 / 个人简介 / 合作联系」三层重复标题**，桌面两栏顶部「AI 影像创作者」与「开始合作」字号、基线一致，分别连接简介与合作信息；它们是卡片内容标题而非滚动章节标题，不独立执行文字动画；邮箱与微信保持无框且可直接操作，点击热区全端 ≥44px，数值文字 15px/600，桌面维持右对齐，hover 仅有轻细下划线，键盘焦点有清晰轮廓；手机单栏依次为职业定位、简介、合作标题、说明、邮箱/微信、底部社交图标。只保留一道社交区顶部分隔线，保留现有 6 个社交入口。桌面社交区左侧保留品牌头像和 AI路人落款，手机端隐藏整个重复品牌行，不保留空占位。#profile-title 仍作为该章节的有效语义标题，#contact-title 仍作为 CTA 锚点；禁止改动现有邮箱、微信复制或入口链接。

## Hero 发布效果一致性

### CSS 规则归属与回归防重复

- **禁止末尾叠加补丁式 CSS**：修改导航、Hero、播放器或工作台时，先搜索该选择器在当前文件及全部公共样式中的已有声明（包括媒体查询和 `!important`），在负责的原规则中修改。只有确需不同响应式/状态行为才增加专属选择器，不能为覆盖旧版继续叠一层 `!important`。
- **区分安全冗余与合法回退**：同文件、同媒体条件、同选择器、同属性中，后方同等或更高优先级的声明可在验证后清理。不能机械删除 `vh/lvh/dvh` 等浏览器兼容回退、不同媒体查询、`@supports` 分支或语义不同的组件规则。移除旧声明前后对比 computed style、几何和截图，改变设计效果必须另行评估。
- **工作台样式归属**：`portfolio-workbench/style.css` 负责基础布局和详情/新建工作区；`portfolio-workbench/workbench-enhancements.css` 只补充现行流程和视觉增强。两文件修改同一控制前必须一起检索，不能用新文件掩盖旧错误。浏览器中正在运行的 5190 服务若有代码更新，先重启再执行 `npm run check:workbench-live`。
- **测试以当前规范和真实数据为准**：作品数量由数据/接口计算，不能写死历史总数；文案应复用 `src/i18n/dictionary.js`；手机播放器使用自定义控制条，桌面保留原生控件；封面选帧测试需先进入「封面与海报」Tab；归档/未保存测试只核对目标项目而非在所有作品中搜索通用版本名。
- **防回归门禁**：`npm run check:cascade-contract` 核验 Hero 不重新出现矩形遮罩、手机语言热区 ≥44×44px、280–320px/放大视口下播放器不横向溢出、敏感工作台选择器不重新叠加 `!important`。导航意图锁结束后要根据真实视口重新同步高亮，执行 `npm run check:nav-scroll`。这些自动化与 `npm run check:design-system`、`check:workbench-live` 相互补充，不能以测试通过替代 Safari/iPhone 实机检查。

### 外链、影院和手机视频控制

- **手机外链确认一致性**：网页内所有指向其他域名的 HTTP(S) 链接在触屏设备上统一使用 `ExternalLinkSheet` 进行二次确认；既有页脚／AI 实验室自定义弹窗不得重复触发，AI 自媒体「访问主页」等遗漏入口由 `SiteExternalLinkGuard` 兜底。二次确认面板只显示目标名称（如「小红书主页」）和站外提示，不再单列 xiaohongshu.com 等域名；继续访问仍保留完整 href 和新窗口安全属性。桌面端仍是原生外链，站内导航、下载、邮件与明确的确认后继续访问动作不被重新拦截。回归 `npm run check:external-links`。
- **影院版本切换动效与布局**：同一作品的 A/B/C 版本采用无外框文字 Tab＋底部 2px 选中线，选中线使用 Framer Motion 的克制弹簧（stiffness 400、damping 34、mass .8），文字选中时微微上移 1px；新海报未解码完成前只移动视觉选中线、不替换实际播放源或 `aria-pressed`，海报解码后以约 340ms 的轻微方向位移（8px）+旧海报淡出完成交接（只用于尚未开始播放的两张海报，播放后的画面不叠旧海报），关闭动态效果时直接切换；切换到另一作品时版本轨道按作品 ID 独立重建，绝不跨作品滑动高亮。手机阅读顺序固定为影片→精简播放控制栏→作品名称/分类→版本文字 Tab→轻量上一部/作品序号/下一部；桌面保持原生视频控件。播放器内不显示「全部作品」入口，关闭与返回使用顶部 ×／Esc。中文版本名不折成难读的多行，横版手机画面靠近上半区，竖版影片按比例且信息自然滚动。回归 `npm run check:cinema-version-motion`、`npm run check:cinema-nav-duration` 与 `npm run check:media-presentation`。
- **手机影片底部安全区**：带版本切换的竖屏影片在正常高度手机（≥800px）上适度缩小显示尺寸，保证首次打开时作品箭头完整可见且下方至少有 32px 可视留白，不裁切视频比例；短屏允许自然滚动，绝不用 fixed 浮层覆盖画面。播放器内容末尾预留至少 64px（有系统 safe-area inset 时再留 32px）的空间，箭头触控区保持 ≥44×44px。回归 `npm run check:cinema-controls`。
- **手机视频控制栏**：影院播放器在 ≤760px 手机视口使用一套独立、精简的播放/暂停、进度拖动、时间、静音、倍速（1×／1.25×／1.5×／2×）和全屏控件；左下角 44px 播放/暂停按钮从首次打开即常显、同一位置不跳动；首次进入保留中央播放入口，影片开始后可直接轻点画面暂停/继续（不重置播放时间）；播放/暂停的点击反馈借鉴 YouTube，在画面中央短暂出现 64px 中性深色圆形图标、750ms 非对称贝塞尔缓动（0-150ms 淡入放大、150-600ms 完全显示保持、600-750ms 淡出缩小；透明度/缩放边界一致，进入减速、退出加速，绝不二次放大），且不占用点击层，系统减少动态效果时立即消退；手机倍速采用相对整条控制栏居中的四等分深色薄纱玻璃横向胶囊，复用 `--portfolio-glass-surface` 与 `--portfolio-glass-blur`，减少透明度／模糊不支持时回退 `--portfolio-glass-solid`（不使用浏览器原生白色菜单及四行高菜单），弹层高度约 56px、宽度不超过可视手机内容宽度；选中项复用中性玻璃填充，触控目标至少 44px、单选状态由 `aria-checked` 表达、Esc／外部点击关闭、键盘可操作；手机控制栏继续位于画面下方、桌面原生控制栏不改，缓冲中暂停须恢复可操作的暂停态；每个主要图标按钮至少 44px，放在视频下方，不与浏览器原生控件叠加。未点播放或全屏不加载 MP4。iPhone 通过 WebKit 系统原生全屏播放；Android 等标准 Fullscreen API 环境在全屏内启用视频原生控件，退出后恢复网页控制栏。桌面端保留原来的原生视频控件、布局与播放内核。手机竖版影片独立限高且内容自然滚动、标题仍用完整内容宽度；全程维持 `object-fit: contain`，无裁切或拉伸。回归 `npm run check:cinema-controls`、`npm run check:cinema-fullscreen`、`npm run check:media-presentation`。
