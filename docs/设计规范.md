# 当前设计规范

## 设计方向

这是一个以滚动视频为叙事主线的动态设计师作品集。视觉气质借鉴 Apple 的克制、秩序和空间感，但不复制 Apple 官网，也不把页面改成白色产品页：视频负责氛围，界面负责阅读和行动。

## 视觉系统

- 背景使用中性深黑，禁止大面积蓝黑遮罩和蓝色渐变。
- 主文字使用 `#f5f5f7`，辅助文字使用 `#a1a1a6`，弱信息使用 `#86868b`。
- `#2997ff` 只用于主按钮、当前状态、焦点和必要的可操作提示，不作为普通装饰色。
- 标题、正文使用系统字体栈（优先 SF Pro / PingFang）；年份、编号和少量英文元数据使用等宽字体。
- 导航、Dock、卡片和面板遵循同一套中性深色磨砂材质：半透明黑、约 `22px` 模糊、细边缘高光和克制阴影。
- 同一内容层只保留一个表面，不叠加多层玻璃、强发光或黑色边框。
- 大面板使用 `24px` 圆角，内容卡使用 `18px`，控件使用胶囊圆角；不为装饰额外增加圆角。

## 排版和布局

- 每个章节遵循“章节标题 → 一句说明 → 主要内容”的阅读顺序。
- 大标题使用紧凑字距和行距，正文增加行距；不要用字号堆叠制造信息层级。
- 桌面端以统一内容版心对齐，导航降低存在感，只保留白色文字和极细当前状态线。
- 移动端保持图标入口和固定位置，不增加额外导航文字，不使用桌面式缩放动画。
- 页脚采用左侧联系方式、右侧 Dock 的同网格布局；版权信息与内容版心左边界对齐。
- 模块之间不使用贯穿视口的硬黑分界线，使用留白、视频明暗和局部面板建立节奏。

## 动效和交互

- 滚动视频是唯一的持续叙事动效；章节入场只使用短距离淡入上移。
- 桌面端保留轻量悬停和卡片反馈；移动端以原生滚动、点击按压和焦点反馈为主。
- 工作经历桌面端使用连续阶段索引条：取消拼接圆角和截断装饰线，以当前项底部高亮、轻微抬升和背景变化表达状态；移动端切换为可横向滑动的阶段卡片。
- 奖项卡片默认保持干净表面，仅在可交互状态提供轻量反馈；自媒体四张平台卡片的 hover/press 反馈保持一致，不因是否有外链而改变视觉响应。
- AI 影响力模块不持续大幅运动；Dock 保持结构不变，只做克制的悬停、按压和二维码反馈。
- 动效必须使用 `transform`、`opacity`、边框或背景色等明确属性，禁止无目标的 `transition: all`。
- 默认节奏由 `src/styles/apple-system.css` 的 motion tokens 管理；禁止在组件内重新发明一套时长和缓动。

## 可访问性和维护

- 所有按钮、链接、Tab、灯箱和复制操作必须有清晰的键盘焦点与语义标签。
- `prefers-reduced-motion: reduce` 下停止非必要位移和循环动效；`prefers-reduced-transparency: reduce` 下使用实色面板。
- 视觉系统的 Token 真值在 `src/styles/apple-system.css`，共享表面契约在 `src/styles/card-surfaces.css`。
- 修改排版、文案或响应式规则后，必须执行 `npm run build` 和 `npm run check:i18n`。
