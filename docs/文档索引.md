## 当前容易踩坑的差异

- 首页 8 部精选由 `src/data/projects.js` 中 `FEATURED_PROJECT_IDS` 明确排序：`01, 02, 06, 03, 04, 07, 08, 05`。完整 15 部作品库始终保留 `PROJECTS` 原始顺序；两者不能用“取前 8 件”替代。
- 首页作品封面与全部作品库共享 3:4 比例，桌面/手机都只在封面右下角常驻一个播放提示；播放器按视频真实比例呈现。
- `docs/设计规范.md` 是唯一生效的视觉真值；规范中 Token/选择器如与代码不同，必须核对代码后修改文档，不强行改动生产代码以满足旧描述。
- 自动化通过 `scripts/lib/safe-media.mjs` 拦截 ImageKit；本地原片与 `.cover-studio/` 会话**不自动移动或删除**。
- 屏幕截图、发布记录、原始 MP4 和本地缓存不是 GitHub README 的展示资源；未获得明确授权前不上传。
