## 工程目录约定

- 公开网站：根目录 `index.html`、`works.html`、`vite.config.js`、`netlify.toml`、`package.json` 保持原位；它们是多入口 Vite、Netlify 与包管理的稳定入口。
- 本地管理端：`portfolio-workbench/` 位于根目录。运行 `npm run workbench`；源码修改后先保存草稿，再正常重启 5190 并执行 `npm run check:workbench-live`。测试用工作台只能指向隔离副本，不能另启服务操作正式历史。
- 自动化：`scripts/checks/site/` 验证网页，`scripts/checks/workbench/` 验证工作台；共同使用 `scripts/lib/`、`scripts/fixtures/`。在用的 `npm run check:*` 命令保持兼容；经覆盖迁移的旧测试可删除，改路径先执行 `npm run check:repo-layout`。
- 测试截图和临时审计集中在 Git 忽略的 `.audit/`，旧 `.oil-ui/` 已归档到 `.audit/legacy-oil-ui-20261111/`；不要把原始视频、回收历史、未授权客户素材推到公开 GitHub。

## 当前容易踩坑的差异

- 当前登记 **19 部作品、23 条视频**（不含未来归档状态）：商业广告 9、创意短片 4、海外产品广告 4、视觉实验 2。ID 16、18、19 含多版本。`src/data/project-order.json` 独立管理 **8 个可替换的首页精选 ID** 与全部作品顺序，`src/data/archive-state.json` 维护可恢复的隐藏状态；`works.html` 只有四个分类 Tab，默认商业广告。
- 首页作品封面与全部作品库共享 3:4 比例，桌面/手机都只在封面右下角常驻一个播放提示；播放器按视频真实比例呈现。打开前须解码独立播放器海报，不能为等海报先显示空弹窗。
- 全部作品页面左侧 A+ 返回控件（圆形箭头 +「首页 / Home」）在桌面、手机都回首页首屏；中央的「精选作品 / Featured」另跳 #projects，详情弹窗使用头像品牌。
- 获奖画廊同时展示全部 8 张：≥1280px 八列，≤1279px 四列两排；手机仅显示图片，标题与奖项说明在查看器中呈现。确认见 `check:award-pagination`。
- `docs/设计规范.md` 是首页与全部作品页共享的视觉真值；工作台专有操作／几何规则归 `docs/本地封面工作流.md`。规范中 Token/选择器如与代码不同，先核对实际生产行为并更新文档，不能强行改代码满足旧描述。
- 当前登记 19 张 3:4 封面和 23 张独立播放器海报，按四分类目录、英文作品名存放；包括 FormFunk 创意广告 C 版海报。作品及视频版本的命名、排序、归档、封面替换、恢复与 ImageKit 真值请统一参照 [作品库维护](./作品库维护.md) 和 [本地工作台技术维护](./本地封面工作流.md)，不要在索引重复编辑流程。本地 .cover-studio/ 的修订历史不得清理；改名不影响已上传 ImageKit URL。
- 屏幕截图、发布记录、原始 MP4 和本地缓存不是 GitHub README 的展示资源；未获得明确授权前不上传。
