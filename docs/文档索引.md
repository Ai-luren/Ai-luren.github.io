## 当前容易踩坑的差异

- 当前登记 **18 部作品、21 条视频**（不含未来归档状态）：商业广告 9、创意短片 3、海外产品广告 4、视觉实验 2。ID 16、18、19 含多版本。`src/data/project-order.json` 独立管理 **8 个可替换的首页精选 ID** 与全部作品顺序，`src/data/archive-state.json` 维护可恢复的隐藏状态；`works.html` 只有四个分类 Tab，默认商业广告。
- 首页作品封面与全部作品库共享 3:4 比例，桌面/手机都只在封面右下角常驻一个播放提示；播放器按视频真实比例呈现。打开前须解码独立播放器海报，不能为等海报先显示空弹窗。
- 全部作品页面左侧 A+ 返回控件（圆形箭头 +「首页 / Home」）在桌面、手机都回首页首屏；中央的「精选作品 / Featured」另跳 #projects，详情弹窗使用头像品牌。
- 获奖画廊同时展示全部 8 张：≥1280px 八列，≤1279px 四列两排；手机仅显示图片，标题与奖项说明在查看器中呈现。确认见 `check:award-pagination`。
- `docs/设计规范.md` 是唯一生效的视觉真值；规范中 Token/选择器如与代码不同，必须核对代码后修改文档，不强行改动生产代码以满足旧描述。
- 18 张 3:4 封面和 21 张原比例海报按四分类目录、英文作品名存放；工作台作品库**单击标题**或详情中直接编辑作品中英文名，英文变更会同步重命名本地 MP4、图片与 JSON 引用，不改云端 URL。视频版本名独立维护，右侧「作品管理」汇总视频版本、共享名称、ImageKit 和精选；版本单击切换或拖拽排序，点铅笔或「重命名当前版本」修改中英文，无需双击。旧作品新增版本使用 `legacy-video-variants.json`，新作品的版本使用 `auto-projects.json`。`.cover-studio/` 历史备份不可清理。自动化通过 `scripts/lib/safe-media.mjs` 拦截 ImageKit。
- 屏幕截图、发布记录、原始 MP4 和本地缓存不是 GitHub README 的展示资源；未获得明确授权前不上传。
