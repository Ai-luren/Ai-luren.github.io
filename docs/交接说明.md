# 项目交接说明

## 运行方式

```bash
npm ci
npm run dev
npm run build
```

开发服务默认使用 `http://127.0.0.1:5174/`。生产构建输出到 `dist/`，Vite 构建时使用相对路径以兼容 GitHub Pages 根地址和子路径。

当前线上地址（国内访问优先）：<https://ailuren.pages.dev/>。

同一仓库还同步部署到：

- GitHub Pages：<https://ai-luren.github.io/>
- Vercel：<https://ailuren.vercel.app/>
- Netlify：<https://ailuren.netlify.app/>

四个平台均连接 `Ai-luren/Ai-luren.github.io` 的 `main` 分支，构建命令为 `npm run build`，发布目录为 `dist`。Cloudflare Pages、Vercel 和 Netlify 会在合并到 `main` 后自动部署；GitHub Pages 由 `.github/workflows/deploy-pages.yml` 部署。

## 运行时结构

`index.html` 是页面主体，包含章节结构、全局 CSS、背景视频、GSAP/ScrollTrigger 脚本和静态文案。`src/main.jsx` 等待 `window.__gsapReady` 完成后启动 React，`src/App.jsx` 通过 portal 将交互模块挂载到页面预留节点：

- `#projects-react-root` → `MagneticProjectArchive`：精选创作档案（分类标签 + 3:4 彩色封面 + 标题 + 观看入口/奖项，文字在封面卡外）和鼠标跟随倾摆。
- `#recognition-react-root` → `ImpactEvidence`：获奖截图（横向滚动条 `.impact-award-rail` + 点击放大灯箱 `.impact-award-lightbox`，灯箱经 Portal 挂 body）、平台 Logo 和四个平台内容发布卡片。
- `#footer-dock-react-root` → `FloatingDock`：页脚社交入口和复制操作。
- `#experiments-react-root` → `ExperimentFlip`：AI 实验室交互卡片。
- `#hero-actions-react-root`、`#hero-title-react-root` → Hero 操作和标题动效。
- `VideoPostProcess`：背景视频后处理。
- `#profile .career-strip`：倒叙工作经历模块；`.career-tabs` 是原生 ARIA Tab 列表，`.career-detail` 是唯一详情面板，桌面端分栏、移动端横向滑动。

其余章节目前由 `index.html` 直接渲染。

## 当前设计真值

- 全局基调是中性深黑；滚动视频负责氛围，界面负责阅读秩序。
- `src/styles/apple-system.css` 是字体、颜色、间距、动效和响应式表现的主入口；`src/styles/card-surfaces.css` 负责共享磨砂表面契约。
- 主文字使用 Apple 风格白灰阶，蓝色只用于主按钮、当前状态、焦点和必要的可操作提示。
- 桌面导航只保留低存在感文字和极细当前状态；移动端保持图标入口和固定位置。
- 章节采用短距离淡入上移；移动端关闭桌面式倾斜、缩放和持续轨道运动。
- 页脚使用左侧联系方式、右侧 Dock 的同网格布局，版权信息与内容版心左边界对齐。

## 维护注意

- 修改文案时优先查找 React 数据数组或 `index.html` 对应节点，不要在构建产物 `dist/` 中直接改。
- 修改 `ImpactEvidence` 时同步检查桌面端和移动端 CSS，尤其是 Logo 尺寸、卡片底部数据和内容换行。
- 修改工作经历时同步更新 `careerItems`、`.career-tab` 和 `.career-detail` 的倒叙顺序；保持 `aria-controls="career-panel"`、`aria-labelledby` 和 `data-career-index` 一致。
- 修改工作经历交互时检查 Tab 的 `aria-selected`、roving `tabindex`、Left / Right / Home / End 键盘切换，以及移动端阶段标签的横向滚动和 44px 触控热区。
- 桌面工作经历阶段索引是连续的横向阶段条，不使用独立卡片圆角或竖向装饰线；当前项用底部高亮，hover/focus 使用轻微抬升和背景反馈。移动端仍保持独立阶段卡片和原生横向滑动。
- 获奖卡片默认不使用大块阴影，hover/focus 只提供轻量边缘与位移反馈；抖音、小红书、快手和视频号四张自媒体卡片保持一致的 hover/press 反馈，视频号当前是无外链的展示卡。
- 修改作品档案 3D 效果时保留键盘焦点和 reduced-motion 分支。
- 修改 GSAP 加载或 `CometCard` 时保留 `window.__gsapReady` 等待逻辑，避免 React 初始化早于 GSAP 导致鼠标 3D 监听未绑定。
- 邮箱、电话和社交入口由 `FloatingDock.jsx` 组件渲染（通过 portal 挂载到 `#footer-dock-react-root`）；邮箱图标执行复制邮箱操作，电话和微信图标复制对应号码，其余图标跳转外部主页。
- 交互回归除双语布局检测外，还应运行 `node scripts/check-mobile-project-gestures.mjs` 和 `node scripts/check-mobile-menu-focus.mjs`；若 `check:i18n` 自动启动服务超时，先用 `./node_modules/.bin/vite --host 127.0.0.1 --port 5199 --strictPort` 启动检查服务，再执行 `npm run check:i18n`。
- 旧设计探索页、临时页脚对比页和一次性实施计划不参与运行；新的长期规则只写入本目录的 `AGENTS.md` 和 `docs/`。删除独立旧文件前先确认没有外部引用。
